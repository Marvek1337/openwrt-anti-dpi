# Установка на OpenWrt

## 1. Проверка

- Зайдите в LuCI и подтвердите модель, аппаратную ревизию, версию прошивки.
- Подключитесь по Ethernet или подготовьте аварийный доступ к роутеру.
- Выполните `sh scripts/diagnostics.sh`. Проверьте `/overlay`, архитектуру, `fw4` и `nft`.
- Не удаляйте компоненты firewall, DHCP, Wi-Fi и ядра ради освобождения памяти.

## 2. Резервная копия

```sh
sh scripts/backup.sh
```

Скачайте архив с роутера, храните локально в безопасном месте. Backup **может содержать пароли**.

## 3. Официальный релиз

Откройте [Zapret2 Releases](https://github.com/bol-van/zapret2/releases), изучите release notes и выберите совместимый архив для OpenWrt. Сверьте SHA256 по независимому доверенному каналу. При отсутствии доверенной контрольной суммы сначала изучите происхождение и содержимое релиза — не вводите произвольный хеш.

## 4. Установка

```sh
sh scripts/install.sh
```

Вставьте адрес релиза и ожидаемый SHA256; подтвердите установку. Скрипт проверит место и хеш, затем передаст управление штатному `install_easy.sh` из архива. Установщик upstream может установить дополнительные зависимости, изменить правила firewall и предложить выбор режима. **Читайте все вопросы установщика.**

> Минимальный порог 4 MiB в нашем скрипте — защитный, а не официальное требование Zapret2. Конкретный расход места зависит от сборки и зависимостей.

## 5. Подбор стратегии

Не вставляйте случайные наборы `--dpi-desync` из интернета. Используйте средства проверки, входящие в выбранную версию Zapret2, и её официальную документацию. Сначала проверьте DNS, затем доступность отдельных ресурсов и работу TCP/UDP.

## 6. Проверка

- Интернет работает с включённой и выключенной обработкой.
- Проверены несколько клиентов в LAN и Wi-Fi.
- Нет заметных проблем с обычными сайтами, видеосвязью, играми.
- После перезагрузки конфигурация сохраняется.

## 7. Откат

Штатное удаление: `sh scripts/uninstall.sh`. Если доступ к роутеру потерян, используйте LAN/консоль и резервную копию. Не выполняйте `sysupgrade -r` вслепую на другой версии прошивки.

См. [диагностику](TROUBLESHOOTING.md).
