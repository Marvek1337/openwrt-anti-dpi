# Диагностика и восстановление

| Симптом | Действие |
|---|---|
| Мало свободного места | Проверить `df -h /overlay`; не удалять системные пакеты |
| Нет `fw4`/`nft` | Уточнить версию прошивки и систему firewall |
| Не работает один сайт | Проверить DNS, IPv4/IPv6, протокол TCP/QUIC |
| Не работает весь интернет | Остановить установленный upstream-сервис; проверить маршруты и firewall |
| После перезагрузки сломался доступ | Ethernet/консоль, штатный recovery и резервная копия |
| Установщик не нашёл бинарник | Проверить архитектуру, состав релиза и документацию upstream |

## Команды чтения состояния

```sh
cat /etc/openwrt_release
df -h /overlay
free -m
logread | tail -n 80
```

**Не публикуйте** конфиги целиком, дампы трафика, backup, токены, пароли Wi-Fi, ключи VPN или WAN-адреса. Перед отправкой логов проверьте их вручную.

## Откат

Сначала используйте штатный `uninstall_easy.sh` установленной версии; резервную копию восстанавливайте только при совместимости прошивки и понимании её содержимого.
