# Безопасность

- Никогда не сохраняйте пароли SSH, LuCI, Wi-Fi, VPN или токены в Git.
- Смена пароля root после передачи его третьим лицам обязательна.
- Архивы резервных копий OpenWrt конфиденциальны; храните офлайн и с ограничением прав.
- Используйте релизы только официального Zapret2; проверяйте источник и SHA256.
- Запуск стороннего установщика от root даёт ему полный доступ к роутеру.
- Не открывайте SSH/LuCI в интернет ради удобства установки.
- Этот репозиторий не утверждает, что стратегии обхода протестированы на любом оборудовании.
