# Настройка Anti-DPI

## Как это устроено

Zapret2 — средство обхода некоторых механизмов DPI без туннеля и внешнего VPN-сервера. Варианты стратегии и синтаксис конфигурации зависят от конкретной версии upstream.

## DNS

Проверяйте DNS отдельно от DPI. При подмене ответов DNS даже корректная стратегия может не помочь. Не меняйте DNS провайдера без необходимости и не отключайте защитные функции сети ради экспериментов.

## Протоколы

| Трафик | Типичный порт | Что проверять |
|---|---|---|
| HTTP | TCP/80 | Раздельная диагностика HTTP |
| HTTPS | TCP/443 | TLS, SNI и поведение браузера |
| QUIC | UDP/443 | HTTP/3 и мобильные приложения |

## Firewall

На современных OpenWrt распространён firewall4 (`nftables`). Не вставляйте устаревшие правила `iptables` без проверки совместимости. Flow offloading может влиять на работу перехвата; проверяйте это на своей версии прошивки.

## Принципы

1. Регистрируйте базовую работоспособность до установки.
2. Меняйте только одну настройку за раз.
3. Сохраняйте предыдущую рабочую стратегию.
4. Проверяйте одновременно обход и обычный интернет.
5. Помните, что блокировка по IP и некоторые серверные механизмы не решаются десинхронизацией DPI.
