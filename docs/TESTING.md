# Тестирование

Запуск статических проверок:

```sh
shellcheck --shell=sh scripts/*.sh tests/*.sh
sh tests/smoke.sh
```

`tests/smoke.sh` рассчитан на Linux-машину **без** файла `/etc/openwrt_release`: он проверяет синтаксис и защиту от запуска не на OpenWrt.

GitHub Actions выполняет эти проверки на Ubuntu при push и pull request.

## Что они не проверяют

- совместимость с конкретной аппаратной ревизией;
- наличие официального архива выбранного релиза;
- правильность стратегии DPI и работу DNS;
- работоспособность LuCI/Wi-Fi после изменений;
- установку и удаление на реальном маршрутизаторе.

Перед объявлением стабильного релиза нужны hardware-in-the-loop испытания и проверка восстановления после неудачной установки. Пока проект имеет статус **beta**.
