# OpenWrt Anti-DPI 🛡️

> Удобный набор сценариев для диагностики и развёртывания **Zapret2** на маршрутизаторах с OpenWrt.

![OpenWrt](https://img.shields.io/badge/OpenWrt-supported-00A3E0?logo=openwrt)
![Shell](https://img.shields.io/badge/Shell-POSIX-green)
![Status](https://img.shields.io/badge/status-beta-orange)
![License](https://img.shields.io/badge/license-MIT-blue)

**Anti-DPI ≠ VPN.** Zapret2 изменяет обработку пакетов для противодействия некоторым видам DPI, но не шифрует весь трафик и не скрывает IP-адрес. Не существует стратегии, гарантированно работающей у всех провайдеров.

## Возможности

- Проверка OpenWrt, архитектуры, свободного места, пакетов и firewall.
- Создание резервной копии через штатный `sysupgrade -b`.
- Установка **официального релиза Zapret2**, выбранного вручную.
- Защита от запуска на неподдерживаемой ОС и при нехватке памяти.
- Инструкции по диагностике, проверке стратегии и безопасному откату.

## Быстрый старт

Подключитесь к роутеру по SSH. **Не вводите пароли в команды и не публикуйте файлы резервных копий.**

```sh
ssh root@192.168.1.1
```

Скопируйте каталог проекта на роутер (например, в `/tmp/openwrt-anti-dpi`). Далее:

```sh
cd /tmp/openwrt-anti-dpi
sh scripts/diagnostics.sh
sh scripts/backup.sh
```

Следуйте [инструкции по установке](docs/INSTALL.md). Установщик принимает только ссылку на файл **официального** GitHub Releases и требует явного подтверждения:

```sh
sh scripts/install.sh
```

> Скрипт не удаляет пакеты и не меняет настройки сети самостоятельно. Установка Zapret2 выполняется штатным upstream-инсталлятором после предварительных проверок. Перед применением стратегии необходимо выполнить диагностику.

## Поддержка

Проект ориентирован на OpenWrt; конкретные версии прошивки и платформы должны быть проверены на устройстве. Для OpenWrt 24.x обычно используется `opkg`, в новых версиях может использоваться `apk`. Аппаратную ревизию маршрутизатора и архитектуру **нельзя угадывать**.
